# 홈 학습 패널

홈의 갤러리 영역 오른쪽에 학습 캘린더, 강의별 누적 시청률, 강의 등록 버튼을 표시한다. 제목 아이콘, 흰색 카드, 보라색 진행 막대, 점선 업로드 영역은 `study-dashboard-sidebar-mockup-v2.png` 시안을 따른다.

- `study.lib.php`: 월/날짜 검증, 현재 회원의 기록 조회, 게시물 읽기 권한 확인, 등록 가능한 게시판 조회.
- `ui_study.php`: 서버 렌더링. 로그인 전·기록 없음·기능 비활성 상태를 구분한다.
- `study.js`: 월/날짜 링크를 선택할 때 패널만 갱신한다. 자바스크립트가 없으면 일반 링크로 이동한다.
- `style.css`: 홈 갤러리와 패널의 반응형 배치 및 기존 테마 색상 연동.

## 데이터와 동작

시안의 예시 강의는 사용하지 않는다. `wz.youtube_watch`의 현재 회원 기록 중 최종 시청일, 완료일 또는 연결된 학습 캘린더의 일정 기간에 선택 날짜가 포함되는 강의를 표시한다. 날짜 표시는 기존 캘린더 기간을 따르며, 진행률은 해당 강의의 **현재 누적 시청률**이다. 별도의 일별 시청 이력을 새로 수집하지 않는다.

삭제된 게시물, 현재 읽을 수 없는 게시물, 다른 영상으로 교체된 게시물은 목록과 날짜 표시에서 제외한다. 모든 시청 기록 조회는 현재 로그인한 회원 ID로 제한하며, 개인 기록을 공용 최신글 캐시에 저장하지 않는다.

강의 업로드 버튼을 누르면 홈 갤러리에 설정된 게시판 중 등록 가능한 게시판을 선택할 수 있다. 선택 후 기존 `bbs/write.php`의 강의 작성·파일 첨부 기능을 이용하며, 최종 등록 권한은 기존 작성 화면에서 검사한다. 로그인 전에는 로그인 화면으로 연결한다.

홈의 연속된 첫 갤러리 행 옆에 패널을 배치하고 공지사항 등의 후속 행은 전체 너비로 표시한다. 현재 AI Agent와 AI Skill은 각각 8개로 설정하여 넓은 PC 화면에서 4열·2행을 구성한다. 개수는 기존 위젯 편집 화면에서 변경할 수 있다. 위젯 편집 모드에는 학습 패널을 표시하지 않는다.

## 확인한 항목

- PHP 및 JavaScript 구문 검사.
- 실제 서버의 비회원 화면과 로컬 PHP로 렌더링한 회원 화면의 월 이동·날짜 선택·강의 등록 게시판 선택.
- 기존 시청 기록 조회, 누적 진행률, 회원별 분리, 읽기 권한 제한, 잘못된 날짜, 윤년 및 4/5/6주 달력.
- Chrome 1440/1024/768/390/360px 화면의 가로 넘침, 다크 모드, 위젯 편집 모드 유지.

검증 과정에서 강의 게시물이나 시청 기록을 새로 등록하지 않았다.
