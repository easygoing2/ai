# 나만의 AI 플랜 노트

> AI 학습 자료를 분야별로 모으고, 유튜브 시청 진도와 개인 학습 일정을 함께 관리하는 그누보드 기반 커뮤니티입니다.

- 운영 사이트: [ai.23yellow.com](https://ai.23yellow.com/)
- 저장소: [easygoing2/ai](https://github.com/easygoing2/ai)
- 기본 브랜치: `main`

## 프로젝트 소개

`나만의 AI 플랜 노트`는 AI 관련 뉴스, 영상, 튜토리얼과 학습 자료를 한곳에 정리하는 서비스입니다.
일반적인 콘텐츠 게시판 기능에 회원별 유튜브 시청률 저장과 개인 캘린더를 결합하여, 자료를 발견하는 것에서 끝나지 않고 실제 학습 진행 상황까지 관리할 수 있도록 구성했습니다.

## 주요 기능

### AI 콘텐츠 아카이브

- AI 뉴스, AI Agent, AI 엔지니어링, AI MCP 자료 분류
- AI Skill의 개념·기획·디자인·개발·마케팅 자료 분류
- Vector RAG, Graph RAG, Vector DB, Python 학습 자료 제공
- 유튜브 영상, 요약문, 참고 링크를 결합한 게시물
- 통합 검색, 최신글, 댓글, 질문답변과 자유게시판

### 유튜브 학습 진도 관리

- 로그인 회원별 영상 시청 구간 저장
- 여러 번 나누어 시청해도 기존 기록과 합산
- 건너뛴 구간과 중복 시청 구간을 제외한 실제 시청률 계산
- 상세 화면의 실시간 시청률·누적 시간·저장 상태 표시
- 게시물 목록의 `미시청`, `시청 중`, `시청 완료` 상태 표시
- 기본 90% 시청 시 완료 처리하며 관리자 설정으로 기준 변경 가능
- 네트워크 실패 구간 임시 보관과 재접속 시 복원

> 이 기능은 사이트 내부에 삽입된 유튜브 플레이어의 시청 구간만 기록합니다. 유튜브 계정의 전체 시청 기록을 가져오지 않습니다.

### 개인 학습 캘린더

- 로그인 회원 전용 월간 캘린더
- 일정·분류 등록, 수정, 삭제
- 같은 날짜 내 일정 순서 변경
- 다른 날짜로 일정 드래그 이동
- 여러 날짜 일정의 기간을 유지한 채 이동
- 모바일 길게 누르기와 키보드 대체 조작 지원
- 시청률 기준 도달 시 학습 영상을 종일 일정으로 자동 등록
- 동일 영상의 일정 중복 생성 방지
- 회원별 일정과 시청 데이터 격리

### 사이트 운영 기능

- JSON 기반 메인 페이지 위젯 빌더
- 여러 게시판을 합친 최신 콘텐츠 위젯
- 테마 색상·폰트·로고·슬라이더 설정
- 라이트·다크 모드
- 사이트 검색과 반응형 내비게이션
- 날씨 위젯과 오늘의 한 줄
- 관리자용 캘린더 환경설정과 익명 이용 통계

## 학습 처리 흐름

1. 회원이 사이트 내 유튜브 영상을 재생합니다.
2. 브라우저가 정상적으로 시청한 영상 구간을 수집합니다.
3. 서버가 기존 구간과 병합하고 중복을 제거해 시청률을 다시 계산합니다.
4. 설정된 기준에 도달하면 시청 완료 상태로 변경합니다.
5. 캘린더 자동등록 기준도 충족하면 해당 회원의 개인 캘린더에 일정을 한 번만 생성합니다.

## 설치 및 배포 시 주의사항

이 저장소는 운영 사이트 소스를 관리하기 위한 프로젝트이며, 보안상 일부 서버 설정과 운영 데이터는 포함하지 않습니다.

다음 항목은 별도로 준비해야 합니다.

- PHP와 MySQL을 사용할 수 있는 웹 서버
- 그누보드 데이터베이스와 운영 환경 설정
- `config.php`, `common.php`, `data/dbconfig.php` 등 서버별 설정 파일
- 캘린더와 유튜브 시청률 플러그인의 설정·DB 스키마
- 파일 업로드, 세션, 캐시 디렉터리의 쓰기 권한
- 웹 서버의 Pretty URL 및 HTTPS 설정

배포 전에는 반드시 다음 순서로 확인합니다.

1. 운영 데이터베이스와 파일을 백업합니다.
2. 별도의 테스트 환경에서 PHP 문법과 주요 페이지를 확인합니다.
3. 캘린더와 시청률 플러그인의 스키마 버전을 확인합니다.
4. 테스트 회원 계정으로 데이터 격리와 저장 API를 검증합니다.
5. PC와 모바일에서 영상 재생·진도 저장·캘린더 등록을 확인합니다.
6. 이상이 없을 때 운영 환경에 반영합니다.

## 보안 원칙

- 비밀번호, API 키, 개인 액세스 토큰과 DB 접속정보를 저장소에 커밋하지 않습니다.
- 브라우저 쿠키와 로그인 세션 파일을 저장소에 커밋하지 않습니다.
- 모든 저장 API는 로그인, CSRF 토큰과 현재 회원의 소유권을 확인합니다.
- 게시물·영상·일정 식별자는 클라이언트 값을 그대로 신뢰하지 않고 서버에서 검증합니다.
- 회원 탈퇴 시 개인 일정 및 시청 기록 처리 정책을 함께 확인합니다.
